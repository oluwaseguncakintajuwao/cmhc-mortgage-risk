# Project Scope

## Business Framing
This project is framed as a mortgage default risk and insurance pricing exercise relevant to a housing finance institution.

## Core Questions
1. Which borrower characteristics are most associated with default risk?
2. How can borrower-level risk be translated into pricing signals?
3. How do 2025 mortgage rate assumptions affect affordability and risk?
4. How does portfolio risk change under stress scenarios?

## Initial Deliverables
- Cleaned dataset
- Feature engineering pipeline
- Baseline default model
- Risk segmentation
- Pricing logic
- Scenario analysis
- Documentation and reproducible environment
