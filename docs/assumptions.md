# Assumptions Log

1. The source dataset is treated as if it reflects borrower conditions in 2025.
2. The target variable is interpreted as a proxy for mortgage-related default risk.
3. Mortgage-specific variables not present in the original dataset may be engineered using documented assumptions.
4. Canadian mortgage rate assumptions will be introduced later using 2025 market context.
5. This is a prototype for modelling and decision-support purposes, not a production underwriting system.
