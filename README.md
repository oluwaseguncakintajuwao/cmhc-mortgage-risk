# CMHC Mortgage Risk & Insurance Pricing Model

## Overview
This project develops a mortgage default risk and insurance pricing prototype using a real-world consumer credit dataset reframed for mortgage risk analysis.

## Objectives
- Estimate probability of default (PD)
- Engineer mortgage-relevant features
- Incorporate 2025 Canadian mortgage rate assumptions
- Simulate stress scenarios
- Derive simple risk-based pricing outputs
- Structure the workflow in a reproducible DevOps-style environment

## Tech Stack
- Python
- WSL
- VS Code
- scikit-learn
- pandas
- Git
- GitHub Actions

## Project Structure
- `data/`: raw and processed data
- `src/`: modular pipeline code
- `docs/`: assumptions, scope, model notes
- `tests/`: unit tests
- `scripts/`: reproducible run scripts
